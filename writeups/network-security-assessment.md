# Network Security Assessment

## Objective
Assess network connectivity and security controls within an isolated cybersecurity lab environment.

## Lab Environment
- Kali Linux — Security testing workstation
- Ubuntu Linux — Target system
- pfSense — Firewall, routing, DHCP and network segmentation
- Oracle VirtualBox — Virtualization platform

## Assessment Activities
- Network connectivity testing
- Host discovery
- Port and service scanning
- Firewall rule validation
- Network segmentation testing
- Traffic and exposure analysis

## Tools
- Nmap
- Ping / ICMP
- Linux networking utilities
- pfSense

## Security Focus
The assessment is performed within an isolated lab environment to evaluate network visibility, exposed services, firewall behavior and security controls.
